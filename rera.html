  • AI-driven WhatsApp chatbot (NLU + retrieval augmentation)
  • Property intelligence micro-site (dynamic components)
  • Unified engagement & conversion API gateway

AI Intelligence Layer

  • RAG over verified disclosure corpus + FAQs
  • Buyer persona inference & lead qualification matrix
  • Adaptive dialogue flows based on interaction intent signals
  • Predictive funnel stage progression probability scoring
  • Anomaly detection for fraud / misuse patterns

Conversational Journey Orchestration

  1. Scan QR → Verified landing handoff or direct WhatsApp deep link.
  2. Chatbot greets with dynamic trust capsule (project snapshot + legitimacy hash).
  3. Adaptive questioning identifies budget, timeline, use-case (invest/live).
  4. Structured intent vector generated → scoring pipeline updates CRM in real time.
  5. Trigger personalized collateral (floor plans, pricing bands, offers) with monitored engagement event streams.

Design Principle

Zero duplication, zero re-keying: each user action produces structured, attributable data augmenting an evolving market intelligence graph.

Data Fabric & AI Enablement

Data Ingestion

  • Regulatory filings (structured → normalized schema)
  • Developer-provided inventory & pricing APIs
  • Chat interaction transcripts (token-curated)
  • Intent events (scan, dwell, asset open, re-engage)
  • Session metadata (device, geolocation granularity)

Processing Pipelines

  • Event streaming (Kafka / Pulsar)
  • Semantic enrichment (entity resolution, PII masking)
  • Vectorization (embedding store for RAG)
  • Lead enrichment (external data signals optional)
  • Fraud heuristics (rate anomalies, signature mismatch)

AI Models

  • NLU intent classifier (multi-label: verification / pricing / investment / support)
  • Engagement propensity model (time-based recency & feature vector)
  • Lead score (weighted composite: budget fit, urgency, interaction depth)
  • Churn risk (drop-off pattern recognition)
  • Response optimization (A/B multi-arm bandit for prompts)

Governance

  • PII redaction guardrails pre-embedding
  • Explainable scoring thresholds archived
  • Audit log immutability hashing
  • Versioned prompt templates (registry)
  • Model drift telemetry (feature distribution watch)

Illustrative Data Flow

Scan QR → Session Token → AI Gateway → Intent Classification → RAG Answer → Event Stream → Scoring Engine → CRM Sink → Analytics Warehouse.

Each step appends structured metadata creating a continuously improving reinforcement loop for model refinement & business intelligence.
